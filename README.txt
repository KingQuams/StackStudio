STACK STUDIO — Undo / Redo Stack Visualizer

RUN IT
1. Extract the ZIP file.
2. Open index.html in a modern browser (Chrome, Edge, Firefox, or Safari).
3. Type in the editor, then use Undo / Redo to watch the stacks update.

FEATURES
- Two visual stacks with animated state cards
- Undo and redo text history
- LIFO explanations and operation timeline
- Keyboard shortcuts: Ctrl/Cmd+Z, Ctrl/Cmd+Shift+Z, Ctrl+Y
- Sample text, clear confirmation, character counter
- Responsive layout and reduced-motion support

TECH
Plain HTML, CSS, and JavaScript. No install, build tools, or server required.
